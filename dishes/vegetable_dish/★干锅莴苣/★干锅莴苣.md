# 干锅莴苣（香辣入味，焦香下饭）
## 食材准备
| 食材 | 用量 | 备注 |
|------|------|------|
| 莴苣 | 1根（约500g） | 选脆嫩、表皮无斑点的 |
| 五花肉 | 150g | 肥瘦相间，煸出油更香 |
| 干辣椒 | 5-6个 | 剪段，不吃辣可减少 |
| 花椒 | 1小把 | 增香，可选青花椒 |
| 大蒜 | 5瓣 | 切片 |
| 生姜 | 1小块 | 切丝 |
| 青红辣椒 | 各1个 | 切小块，配色提味 |
| 洋葱 | 半个 | 切小块，增香解腻 |
| 调味料 | - | - |
| 盐 | 少许 | 莴苣腌制用，后续少放 |
| 豆瓣酱 | 1勺 | 郫县豆瓣，炒出红油 |
| 生抽 | 1勺 | 提鲜，不额外放老抽 |
| 食用油 | 适量 | 五花肉出油，不用多放 |

## 详细步骤
1. **处理莴苣，逼出水分**
    - 莴苣削去硬皮，切成**滚刀块**（大小均匀，约3cm见方）。
    - 放入盆中，加**半勺盐**抓拌均匀，腌制**20分钟**，让莴苣析出多余水分。
    - 腌好后用清水冲洗掉表面盐分，捞出**彻底沥干水分**（这一步是关键，避免干锅变成水煮菜）。

2. **煸炒五花肉，炼出油脂**
    - 五花肉切成**薄片**；干辣椒剪段，姜蒜切片，青红椒、洋葱切块备用。
    - 锅烧热，**不放油**，直接放入五花肉片，小火慢慢煸炒。
    - 炒至五花肉**微微发黄、油脂析出**，捞出肉片，锅里留煸出的猪油（香而不腻）。

3. **炒香底料，加入莴苣**
    - 锅中留的猪油烧热，放入**花椒、干辣椒段、姜蒜片**，小火炒出香辣味。
    - 加入**1勺豆瓣酱**，快速翻炒至**炒出红油**（注意火候，别炒糊豆瓣酱）。
    - 倒入沥干水分的**莴苣块**，转大火快速翻炒，炒至莴苣**表面微微发焦、断生**（约2-3分钟）。

4. **调味收汁，完成干锅**
    - 放入煸炒好的**五花肉片**、切好的**青红椒块、洋葱块**，继续大火翻炒均匀。
    - 淋入**1勺生抽**，翻炒至调料裹满食材（豆瓣酱和生抽有咸味，不用额外加盐）。
    - 保持大火翻炒1分钟，让汤汁收干，食材表面干爽焦香，即可出锅。
    - 喜欢干香口感的，可出锅后装入干锅中，底部垫洋葱丝，小火加热2分钟再吃。

## 关键技巧
1. 莴苣**一定要腌制沥干水分**，否则炒出来软烂，没有干锅的焦香口感。
2. 五花肉**先煸出油**，既能减少油腻，又能让油脂的香味融入食材。
3. 全程用**大火快炒**，缩短炒制时间，避免莴苣出水变软。
4. 不吃辣的朋友，可去掉干辣椒和花椒，用蒜蓉酱代替豆瓣酱，做成蒜香干锅莴苣。
