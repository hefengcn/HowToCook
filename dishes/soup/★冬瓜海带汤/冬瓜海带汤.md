# 国宴风电压力锅版冬瓜海带汤
olayks立时电压力锅的智能控压功能，能快速炖出食材鲜味，同时锁住营养，做出来的冬瓜海带汤**清鲜不浑浊、食材形态完整**，完全契合国宴对汤品的要求。

## 食材清单（2-3人份）
- **主料**：冬瓜 300g、干海带 50g（或鲜海带 200g）
- **提鲜辅料**：猪排骨 150g、生姜 3片
- **调味**：食用盐 少许、白胡椒粉 少许（可选）、香油 1滴

## 分步制作 
### 1. 食材预处理（国宴级去杂，决定汤的纯净度）
- **海带处理**：干海带用**温水浸泡20分钟**至完全舒展，泡发后用流动清水反复揉搓，刮净表面盐霜和褶皱里的泥沙（杂质会破坏汤的口感，这步不可省）；鲜海带直接焯水1分钟去腥味，捞出过凉切菱形块。
- **冬瓜处理**：去皮去瓤，切成 **2.5cm厚的方块**（厚块能承受持续高温，避免快速软烂成泥，保持方块形态完整，符合国宴 “形整味鲜” 的标准。）。
- **排骨处理**：冷水下锅，加1片姜，大火煮沸焯水2分钟，撇尽浮沫后捞出，用**温水冲洗干净**（冷水焯水逼出腥味，温水冲避免肉质遇冷紧缩，保证排骨鲜嫩不柴）。

### 2. 电压力锅炖制底汤（智能控压省时提鲜）
- 把焯好的排骨、剩余2片姜放入olayks电压力锅内胆，加入**700ml清水**（水量没过食材2指即可，过多会稀释鲜味，这款锅密封性好，不用担心烧干）。
- 盖紧锅盖，**对准合盖刻度线**，选择电压力锅的 **「煲汤」预设档位**（该档位压力和时间适配肉类炖煮，能快速炖出排骨鲜味），默认保压时间一般为15分钟，无需额外调整。


### 3. 加入主料焖煮（防软烂，保国宴级卖相）
- 程序结束后，**等待电压力锅自然泄压**（不要手动按泄压阀，自然泄压能让食材鲜味更融合，且避免汤液喷溅），泄压完成后会自动弹起浮子阀。
- 开盖，放入海带块，开**大火**煮沸，再放入切好的冬瓜块。
- **不盖压力阀，保持锅盖虚掩**，继续用大火煮2分钟，转小火煮6分钟（无高压状态下煮冬瓜，既能煮至边缘透明、筷子轻戳即透，又不会煮烂变形）。

### 4. 国宴级调味出锅（少盐增鲜，不掩本味）
- 加少许食用盐调味（盐必须最后放，避免食材蛋白质提前凝固，鲜味释放不充分）。
- 按喜好撒少许白胡椒粉去腥提鲜，关火后滴1滴香油（仅作点睛，多了会掩盖冬瓜和海带的清鲜）。
- 静置2分钟再盛出，让汤味更融合。

## 适配olayks电压力锅的厨师小贴士
1.  **内胆保养**：这款锅的内胆多为不粘涂层，清洗时用海绵擦拭即可，别用钢丝球刮擦，避免损坏涂层。
2.  **档位替代**：若没有「煲汤」档，可选择「肉类/排骨」档，保压时间调整为12分钟，效果一致。
3.  **汤色把控**：全程避免频繁搅动食材，尤其是冬瓜下锅后，搅动会让汤变浑浊，不符合国宴“汤清如镜”的标准。
